# jira-ticket-skill

A Claude skill that learns your Jira ticket style and generates a personalised ticket writer tailored to you.

## What it does

This is a setup skill. You run it once (or whenever your conventions change), and it produces a separate `jira-ticket-writer.md` skill that you install and use day-to-day to write tickets from a brief.

**Setup flow:**
1. Choose how to provide your existing tickets (Jira MCP, Rovo, or paste)
2. The skill analyses your conventions and extracts them as writing rules
3. You choose which optional standards to bake in
4. Test against 2–3 real briefs with a visible feedback loop
5. Review and confirm the full ruleset
6. It outputs your personalised `jira-ticket-writer.md`

**Then day-to-day:** paste any brief into Claude with `jira-ticket-writer.md` installed → get a fully-formatted ticket in your style.

The `jira-ticket-writer.md` that gets generated by setup is personal to you — it lives wherever you keep your installed skills, not in this repo.

## Install

1. Clone or download this repo
2. Copy the `jira-ticket-skill/` folder into your Claude skills directory
3. Reload skills
4. Say *"set up my Jira ticket skill"* to start

## Data source options

**Jira MCP** — if you have Jira MCP connected, the skill searches your tickets automatically.

**Rovo** — the skill gives you a prompt to paste into Rovo. Rovo does the analysis and returns a structured summary, which you paste back into Claude. No raw ticket data leaves Rovo.

**Manual paste** — pick 5–10 tickets you're happy with and paste them directly into the conversation.

## Optional standards

During setup the skill presents these as a menu — choose what fits your workflow:

- **Accessibility (a11y)** — label + screen reader, keyboard nav, focus management, contrast considerations in the description
- **Security & privacy** — data handling, permissions, PII, input validation prompts
- **Failure & edge cases** — empty states, error states, boundary conditions
- **Acceptance criteria standards** — verifiable AC items written as testable behaviour statements; prompts Claude to push on the brief if scope seems thin rather than padding
- **Story point estimation** — estimate with rationale using Fibonacci scale

## Re-running setup

Re-run this skill whenever your team's conventions change, you move to a new team, or you want to add/remove standards. It'll produce a fresh `jira-ticket-writer.md`.
